# 项目简介

## 项目定位

第一阶段项目为“初中物理教师 Agent + 阿里云百炼千问 API”，目标是使用千问模型完成
初中物理范围内正确、清晰、简洁的文本问答。

## 技术范围

- 使用 Python 3.12 虚拟环境
- 当前入口为 `python main.py`
- 通过 OpenAI 客户端的 `chat.completions` 调用阿里云百炼千问 API
- 使用 `.env` 保存 API Key；该文件已被 Git 忽略且未提交

## 已验证内容

- 平均速度计算题正确得到 `5 m/s`
- 选择并测试金属与木头触感温度的概念题，回答正确解释了导热速度差异
- 缺少 `QWEN_MODEL` 时能够显示清楚的中文配置错误，恢复配置后调用成功

## 边界

当前只实现文本问答，不包含网页、图片输入、数据库、RAG 或 Agent 框架。
