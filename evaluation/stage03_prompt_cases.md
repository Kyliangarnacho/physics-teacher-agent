# Stage 03 固定行为测试用例

- 当前提示词版本：`teacher_v1`
- 当前模型：`qwen3.7-flash`
- 用途：对比提示词修改前后的基本回答行为

这 5 道题分别覆盖简单计算、概念解释、提示请求、错误诊断和条件不足处理。它们用于观察
有限的行为目标，不代表完整的中国初中物理知识与教学能力，也不是有代表性的个人题库。

每道题使用相同的五项评分维度：正确性、逻辑清晰度、教学适配、指令遵循、简洁性。本文件
不预填分数或评价，实际运行后由人工填写。
