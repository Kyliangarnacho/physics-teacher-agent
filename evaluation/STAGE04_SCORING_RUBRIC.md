# Stage 04 文本评测人工评分标准

## 1. 使用范围

本标准用于人工评审 Stage 04 文本题回答。每题从四个维度评分，每项 `0～2` 分，总分
`0～8` 分。

工程脚本只检查结果文件是否完整、版本是否匹配，不自动判断物理结论，也不自动填写人工
分数。

## 2. 四个评分维度

### 2.1 物理正确性

- `2 分`：核心结论、公式、方向、数值和单位均正确，没有与题意冲突的表述。
- `1 分`：核心结论正确，但存在不影响主结论的轻微概念不严谨、表述歧义或次要计算问题。
- `0 分`：核心结论错误、关键规律使用错误、数值或方向错误，或出现致命物理错误。

### 2.2 推理与答案完整性

- `2 分`：回答覆盖题目所问内容和主要 `expected_key_points`，推理链完整，可检查关键步骤，
  结论明确。
- `1 分`：主线可成立，但漏掉一个重要步骤、一个所问分项或必要解释。
- `0 分`：只报结论、推理无法支撑结论，或漏掉多个关键部分导致答案不可用。

### 2.3 条件、研究对象和易错点处理

- `2 分`：正确识别研究对象、适用条件和边界；把最相关的易错点放在对应步骤附近；没有
  擅自补设条件。
- `1 分`：基本识别对象和条件，但遗漏一个重要边界、提醒位置不清楚，或加入了无必要但
  未改变结论的假设。
- `0 分`：研究对象混乱、忽略决定结论的条件、命中数据中列出的关键常见错误，或擅自
  编造条件改变了答案。

### 2.4 个人教学语言风格

- `2 分`：语言像本人，而不是普通教师口语；幽默、吐槽或关系型表达与当前物理错误、条件
  或推理步骤自然相连，具有个人辨识度，同时不影响物理准确性和答案完整性。没有自然
  笑点时不强行开玩笑，也不机械重复固定句式。
- `1 分`：能看出直接、口语化等基础风格，但仍接近通用教师表达；或身份锚点使用生硬、
  重复、位置不贴合当前物理步骤。
- `0 分`：整体是通用客服/百科风格，或机械复制“本质就是”“这个真别错”等句式；又或
  私密玩笑、极端夸张、攻击性表达遮住了教学内容。

## 3. 致命物理错误

“是否存在致命物理错误”是独立的人工判定项。下列情况通常应标记为“是”：

- 最终核心结论、方向、数值或单位错误；
- 使用了不适用的物理规律，导致主推理失效；
- 混淆研究对象或关键条件，导致答案回答了另一道题；
- 给出违反基本物理规律或实验安全要求的建议。

一旦人工确认存在致命物理错误，“物理正确性”应记 `0 分`，人工总评应明确说明。脚本
不得根据关键词自动作出该判断。

## 4. 每题必须填写的人工记录

- 四个维度的分数及简短依据；
- 总分，满分 `8` 分；
- 是否存在致命物理错误；
- 漏掉的关键点；
- 命中的常见错误；
- 机械或不自然的个人句式；
- 人工总评。

若某项没有问题，应填写“无”，不要只留空；尚未评审时保持生成表中的空白占位。

## 5. 确定性预检查

生成脚本只执行以下工程检查：

- 结果 `status` 是否为 `ok`；
- `answer` 是否为非空字符串；
- 评测题 `id` 是否能与结果记录唯一匹配；
- `prompt_version` 是否与该评审表声明的目标版本一致。旧结果表继续检查
  `teacher_v2_personal`，新版复测检查 `teacher_v3_personal_humor`。

预检查通过只表示数据可以进入人工评审，不代表物理答案正确，也不计入四维分数。
