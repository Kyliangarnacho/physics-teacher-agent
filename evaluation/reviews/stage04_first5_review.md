## 1. S04-TXT-001｜光学·凸透镜动态成像

### Question

在凸透镜成清晰实像的实验中，物体最初位于二倍焦距以外。保持物体始终在焦点以外，将物体逐渐靠近透镜。请完整说明像距、像的大小、像的性质和光屏移动方向怎样变化，并指出结论成立的条件。

### Expected key points

- 先确认全过程满足物距大于焦距，仍能成倒立实像
- 物距减小时像距增大，像逐渐变大
- 光屏应远离透镜才能再次得到清晰像
- 若越过焦点，成像性质必须重新分类

### Common errors

- 只背物近像远像变大而不说明焦点边界
- 把靠近透镜误认为任何情况下都能在光屏上得到更大的像
- 漏掉光屏移动方向或实像性质

### Style checks

- 先抓物距与焦距的条件，再说变化
- 使用清楚的动态因果链
- 把焦点边界紧跟在结论后提醒
- 完整作答但不扩写成光学总复习

### Agent 完整回答

> 本质就一句：**实像阶段，物靠近，像必远、必大、必倒立实；光屏得往外退。**
>
> 下面按因果链拆开，自己对照光具座画个简图：
>
> 1. **像距变化**：增大。因为凸透镜成实像时严格遵循“物近像远像变大”。物体靠近透镜 → 物距 $u$ 减小 → 折射光线会聚能力相对过剩 → 会聚点向后推 → 像距 $v$ 增大。
> 2. **像的大小变化**：变大。放大倍数 $m=v/u$，$v$ 涨、$u$ 降，比值必然攀升。过程是：缩小实像 → 等大实像（$u=2f$ 时） → 放大实像。
> 3. **像的性质变化**：**不变**，始终是倒立、实像。因为题干锁定“始终在焦点以外”，$u>f$ 时折射光线实际相交，只能成实像；只有跨过焦点（$u<f$）才会突变正立虚像，本题不触及。
> 4. **光屏移动方向**：远离透镜。光屏是来找像面的，像距拉长了，屏不跟着向外移就会模糊。
>
> **结论成立的条件**（答题漏写直接扣分）：
> - 物体全程满足 $u > f$（这是性质不突变的前提）；
> - 光屏必须**每次重新调节至最清晰位置**（不能假设光屏固定不动）；
> - 符合初中标准实验设定：薄透镜、近轴光线、发光体中心与透镜主光轴等高共线。
>
> 这里真正的坑是：一看到“像变大”就慌着往上加“正立虚像”。求你先看清题目给的硬条件 $u>f$，性质永远锁死在倒立实像。不多说了，抓住“实像区物近像远像变大”这条铁律，这道题就算拿稳了。

## 2. S04-TXT-002｜光学·折射与虚像

### Question

人在岸上看水中的鱼。请完整说明光从哪里传到哪里，为什么眼睛看到的鱼通常比实际位置浅，并判断看到的是实像还是虚像。

### Expected key points

- 光由鱼反射后从水中进入空气，再进入人眼
- 光从水斜射入空气时发生折射
- 人脑按折射光线的反向延长线判断位置
- 看到的是位置较浅的虚像

### Common errors

- 把光线方向说成从眼睛射向鱼
- 只说发生折射，不解释虚像位置
- 把看到的鱼判断为实像

### Style checks

- 开头先说明人看见物体的本质是有光进入眼睛
- 按传播方向到折射再到虚像的顺序解释
- 直接纠正常见方向错误
- 结论明确，不依赖作图

### Agent 完整回答

> 结论先给你：**你看到的是比实际位置变浅的虚像**。光的路径很明确：**从鱼身上反射 → 在水中传播 → 斜射到水面发生折射 → 进入空气 → 最终到达人眼**。
>
> 为什么变浅？抓住这条因果链就行：
> - 鱼反射的光从水斜射向空气（光密→光疏）。
> - 水面处发生折射，**折射角大于入射角**，光线向远离法线方向偏折。
> - 眼睛习惯“光走直线”，接收到光线后会本能地逆着它往回追溯。这些逆推直线的**反向延长线**在实际鱼的上方相交，大脑就把那个交点当成了鱼的位置，看起来自然更浅。
>
> 实像还是虚像？**虚像**。初中判定标准就两条：实际光线有没有真的在那儿汇聚；能不能用光屏接住。这里光线根本没汇过去，只是反向延长线凑出的假点，所以是虚像，且不能用光屏承接。
>
> 这道题考点就锁死在这儿：对象是鱼（发光/反光体）→ 介质是水到空气 → 折射规律定偏折方向 → 反向延长线定像点性质。自己拿纸笔画一条从鱼到眼睛的折射光路，把法线和角度标清楚，就不会再绕进去了。记住“看水下物体永远偏浅、必为虚像”，填空选择直接秒杀。

## 3. S04-TXT-003｜电学·滑动变阻器安全范围

### Question

在串联电路中，电源电压为 6 V，定值电阻 R0=10 Ω，滑动变阻器最大阻值为 20 Ω。电流表量程为 0～0.6 A，电压表并联在 R0 两端，量程为 0～3 V。为保证电表和器材安全，求滑动变阻器接入电路的阻值范围，并写出完整判断过程。

### Expected key points

- 电路电流为 I=6/(10+R)
- 电压表限制为 I×10≤3 V，因此 I≤0.3 A
- 电压表限制比电流表的 0.6 A 更严格
- 由 I≤0.3 A 得 R≥10 Ω
- 结合变阻器自身最大阻值，范围为 10～20 Ω

### Common errors

- 只检查电流表量程
- 忘记电压表测量的是 R0 两端电压
- 求出下限后忘记器材自身最大阻值
- 不比较多个安全限制谁更严格

### Style checks

- 先确认串联关系和电表测量对象
- 分别列限制再取更严格者
- 保留关键代数步骤、单位和范围
- 把最关键的量程坑放在对应步骤旁

### Agent 完整回答

> 结论先摆正：滑动变阻器接入范围是 **10 Ω～20 Ω**。
>
> 这题本质就是找两条安全红线，看哪条更严。串联电路里，电流处处相等，电压按阻值分配，保护器材遵循短板效应——谁先超限，谁卡脖子。
>
> 1. **定最大电流**：电压表并联在 R₀ 两端，量程 0～3 V。因为 U₀ = I·R₀，所以 U₀ 达到顶格 3 V 时，对应支路电流 I₁ = 3 V / 10 Ω = 0.3 A。电流表量程是 0～0.6 A。对比 0.3 A 和 0.6 A，整个电路允许通过的最大电流只能取小值 **0.3 A**。（求你先看清题目条件，电压表先憋不住，它是实际瓶颈，别被电流表量程带偏。）
>
> 2. **算变阻器下限**：电流最大时，电路总电阻必须最小。用欧姆定律 I = U / R 得，R总_min = U / I_max = 6 V / 0.3 A = 20 Ω。串联总阻等于各段阻值相加，所以变阻器最小接入阻值 R滑_min = R总_min − R₀ = 20 Ω − 10 Ω = **10 Ω**。
>
> 3. **定变阻器上限**：滑片往大拨，总电阻变大 → 电流变小 → R₀ 两端分压降低，电表绝对不超量程。因此最大值不受仪表限制，直接取变阻器自身的物理规格上限，即 **20 Ω**。
>
> 最终安全范围：**10 Ω ≤ R滑 ≤ 20 Ω**。你把数值反推一遍检查单位和逻辑，这个真别错。

## 4. S04-TXT-004｜电学·并联故障动态变化

### Question

两个定值电阻并联在理想电源两端，干路和两条支路各接一只电流表。若其中一条支路突然断路，另一支路电流、断路支路电流、干路电流和并联两端电压分别怎样变化？请说明原因。

### Expected key points

- 理想电源端电压不变，并联各支路两端电压不变
- 未断路支路的电阻和电压不变，因此电流不变
- 断路支路电流变为零
- 干路电流等于各支路电流之和，因此减小

### Common errors

- 认为一条支路断路会使另一支路电流也变为零
- 混淆干路电流表和支路电流表
- 脱离理想电源条件死记并联电压不变

### Style checks

- 先判断并联结构和各电流表测谁
- 用支路独立性和电流和关系形成因果链
- 明确理想电源条件
- 按四个待判断量逐项完整回答

### Agent 完整回答

> 先说结论，本质就抓两条：
> - **另一支路电流**：不变
> - **断路支路电流**：直接掉到0
> - **干路电流**：变小（减少的数值正好等于原来那条支路的电流）
> - **并联两端电压**：不变
>
> 原因直接按因果链推，初中电路题只要对象圈对、条件看透，这题就是送分：
>
> 1. **电压为什么不变？** 题目明确是“理想电源”，内阻忽略不计，输出电压死死卡在设定值上。并联网络的两端直接跨接在电源正负极，所以不管外部负载怎么变，并联部分两端电压始终等于电源电压，纹丝不动。
> 2. **另一支路电流为什么不随它变？** 并联各支路独立工作。这条支路的定值电阻 $R$ 没换，它两端的电压 $U$ 也没变（见上一步），根据欧姆定律 $I=\frac{U}{R}$，分子分母都没动，电流自然保持不变。**这里真正的坑是**：很多同学一看到干路电流变了，就惯性觉得其他支路也会被“牵连”。记住，并联不是串联，一支路断路不影响另一支路的供电条件。
> 3. **干路电流为什么变小？** 干路电流等于各支路电流之和，$I_{\text{干}}=I_1+I_2$。一条断路，$I_{\text{断}}\to 0$，剩下的那一条电流维持原值，加在一起当然变小。变化量 $\Delta I_{\text{干}} = I_{\text{原断支路}}$，直接做减法就行。
> 4. **断路支路电流怎么变？** 断路意味着导电通路被物理切断，等效电阻趋向无穷大。代入 $I=\frac{U}{R}$，电流直接归零。这一步基本不用绕弯。
>
> 总结一句：**理想电源保电压，并联支路看各自；一路断，其余支路照常走，干路电流只减不加。** 自己把电路图重画一遍，标出电流走向和电表测的对象，这题就彻底清楚了。

## 5. S04-TXT-005｜电学·灯泡额定状态

### Question

灯泡 L1 标有“6 V 3 W”，L2 标有“6 V 6 W”。两灯串联后逐渐升高电源电压，在不损坏灯泡的前提下，哪只灯先达到额定状态？请完整计算并说明判断依据。

### Expected key points

- 先分别计算额定电流
- L1 的额定电流为 0.5 A，L2 的额定电流为 1 A
- 串联电路中两灯电流相等
- 额定电流较小的 L1 先达到额定状态

### Common errors

- 只比较额定功率大小
- 把谁更亮与谁先达到额定状态混为一谈
- 忽略串联电流相等

### Style checks

- 先指出先达到额定状态取决于额定电流
- 展示必要计算、结果和单位
- 把额定功率与实际状态的区别紧跟判断说明
- 结论直接，不增加无关灯泡知识

### Agent 完整回答

> 结论先放这儿：**L1 先达到额定状态**。
>
> 研究对象是 L1 和 L2。关键条件就一条：**串联→电流处处相等**。电源电压往上爬时，回路电流同步增大，谁需要先跨过的电流门槛低，谁就先“亮到额定”。
>
> 完整计算走三步：
> 1. **求额定电流**（用 $I = P/U$，式中量全是各灯自身的额定参数）
>    - L1：$I_{1额} = 3\text{ W} / 6\text{ V} = 0.5\text{ A}$
>    - L2：$I_{2额} = 6\text{ W} / 6\text{ V} = 1.0\text{ A}$
> 2. **套串联规律**
>    - 串联电路电流相同：$I_{实} = I_1 = I_2$。电流从零开始涨，必须依次经过 0.5 A、1.0 A。
> 3. **比较判断**
>    - 电流刚到 0.5 A 时，L1 刚好满负荷工作；此时 L2 实际电流只有额定的一半。
>    - 若继续升压让电流去够 1.0 A，L1 早就超负荷烧坏了，根本等不到 L2 额定。
>    - 所以 **L1 先到额定状态**，且安全前提下电路允许的最大电流只能卡在 0.5 A。
>
> **这个真别错**：题干问的是“先后顺序”，不是问“最大总电压”。很多同学一上来就算电阻 $R=U^2/P$ 再代串联公式求总电压，绕远不说还容易把非额定状态的灯硬套进比例。抓住“串联电流同一，额定电流小的先触线”这一根主线就够了。单位已经核对，范围也合理，直接填 L1。
