# Stage 05 知识库

## 用途

本目录用于保存可检索、可追踪的初中物理知识卡片，为后续基于资料的回答提供知识库基础。
当前仅建立数据结构，尚未接入模型调用、网页或其他业务逻辑。

## 当前覆盖范围

`physics_notes_v1.jsonl` 当前为空，覆盖范围为零。后续知识卡片应限定在中国初中物理范围，
并按章节和主题逐步整理；在完成来源审计前，不宣称覆盖完整初中物理知识。

## 数据来源

后续内容以项目中已获准使用且经过审计的资料为依据，也可以使用经人工确认的重写笔记。
原始 PDF、Word、截图、完整教辅内容和私有评测材料不直接复制到本目录。每张知识卡片必须在
`source` 字段中记录可追踪的来源说明。

## 隐私与版权要求

- 不记录 API Key、Token、联系方式、学生姓名或其他可识别个人隐私。
- 不保存完整原题、完整教辅章节或大段受版权保护的原文。
- 私有资料继续保存在 Git 忽略目录，不得转移到可提交的知识库文件中。
- 写入前应完成来源、准确性、隐私和版权检查。

## 未处理内容

当前尚未逐份处理原始资料，未完成知识抽取、去重、事实校验、章节覆盖审计和检索效果评测，
也未处理必须依赖图片、图表或 OCR 才能理解的内容。

## 检索计划

当前计划优先使用 BM25 进行关键词检索，而不是向量检索。这样可以先建立可解释、依赖较少的
文本检索基线；是否引入向量检索将在数据规模、召回问题和评测结果明确后再决定。

## 知识卡片格式

`physics_notes_v1.jsonl` 使用 JSONL 格式，每行是一张独立知识卡片，包含以下六个字段：

- `id`：知识卡片的唯一标识
- `chapter`：所属章节
- `topic`：具体主题
- `keywords`：用于检索的关键词数组
- `source`：经过审计的来源说明
- `content`：准确、简洁、可独立理解的知识内容

格式示例仅用于说明字段结构，不代表已经收录的知识卡片：

```json
{"id":"示例ID","chapter":"示例章节","topic":"示例主题","keywords":["关键词1","关键词2"],"source":"示例来源说明","content":"示例知识内容。"}
```
